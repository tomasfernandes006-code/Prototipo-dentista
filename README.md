# VITTORIO – Landing Page (versão modular)
- index.html → estrutura e textos das seções
- css/style.css → design system e responsividade
- js/config.js → DADOS EDITÁVEIS (WhatsApp, endereço, horários, redes, mensagens, tratamentos)
